# 高玉ERP備案

本專案用於規劃與建置「高玉ERP備案」系統，作為企業資源規劃流程的備援、替代或新系統方案。

## 專案目標

- 整理現有 ERP 使用情境與痛點
- 定義備案系統需要支援的核心模組
- 規劃資料結構、權限、流程與報表需求
- 建立可逐步實作與驗證的系統原型

## 初步模組

- 基本資料管理
- 採購管理
- 庫存管理
- 銷售管理
- 生產或工單管理
- 財務與應收應付
- 權限與操作紀錄
- 報表與資料匯出

## 待確認事項

- 使用者角色與權限層級
- 既有 ERP 或 Excel 資料來源
- 是否需要匯入歷史資料
- 是否需要與會計、POS、電商或倉儲系統串接
- 預計使用平台：Web、桌面、內網或雲端
- 技術棧與部署環境

## 建議下一步

1. 定義第一階段必做模組
2. 整理資料表與主要流程
3. 建立系統原型
4. 規劃測試資料與驗收條件
