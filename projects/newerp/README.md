# NewERP Files

This folder stores current NewERP working files published through the Cloudflare site.

## Files

- `files/sop_rolling_12_month_forecast.xlsx`: rolling S&OP forecast, shipment, sell-out, target, achievement rate, and forecast accuracy workbook.
- `files/sop_sales_product_monthly_forecast_template.xlsx`: monthly forecast template for sales input.
- `files/whisky_cost_quote_twd.xlsx`: whisky import cost and TWD quotation workbook using the current 8% gross margin assumption.

## HTML Exports

The `html/` folder contains browser-viewable HTML table exports of the same workbooks. These files can also be opened by Excel when a lightweight web/Excel-compatible format is needed.
