## 第一版模組建議

### 1. 商品管理

先做商品列表、搜尋、篩選、詳情頁。

基本功能：

- 依供應商、型態、產品類別、狀態、交易模式篩選
- 查看成本價、幣別、台幣最低報價、利潤底線
- 查看英文品名、中文品名、規格、EAN、BBD
- 串接商品技術資料

### 2. 供應商管理

先做供應商列表與供應商詳情。

基本功能：

- 查看供應商編號、名稱、國家、幣別、交易條件
- 查看聯絡人、Email、電話、地址
- 查看銀行資訊與敏感資料標記
- 顯示該供應商底下的商品數量與商品列表

### 3. 現金流管理

先做應收應付列表與月份彙總。

基本功能：

- 依月份、PO、供應商、客戶、幣別篩選
- 區分應收與應付
- 顯示台幣金額、外幣金額、預估日期與確認狀態

### 4. PO 追蹤

整合文件、船班與待辦。

基本功能：

- 以 PO 查詢所有追蹤資訊
- 顯示文件缺漏、催收窗口、船班資訊、備註
- 顯示 TDS 或高玉待辦責任歸屬
