# 高玉ERP備案權限設計

建立日期：2026-06-14

## 測試帳號

| 角色 | 使用者名稱 | 使用者密碼 | 說明 |
|---|---|---|---|
| 業務 | `sales` | `gj-sales-2026` | 查看商品、供應商基本資料與 PO 追蹤 |
| 業務主管 | `manager` | `gj-manager-2026` | 查看商品成本、現金流與團隊管理資料 |
| 本人 | `owner` | `gj-owner-2026` | 查看全部資料 |

## 權限範圍

| 功能 / 資料 | 業務 | 業務主管 | 本人 |
|---|---:|---:|---:|
| 總覽 | 可看基本統計 | 可看完整統計 | 可看完整統計 |
| 商品列表 | 可看 | 可看 | 可看 |
| 商品成本價 | 不可看 | 可看 | 可看 |
| 外幣/台幣報價底線 | 不可看 | 可看 | 可看 |
| 供應商基本資料 | 可看 | 可看 | 可看 |
| 供應商敏感資料 | 不可看 | 不可看 | 可看 |
| 現金流 | 不可看 | 可看 | 可看 |
| PO 追蹤 | 可看 | 可看 | 可看 |
| TDS 待辦 | 可看 | 可看 | 可看 |

## 目前原型限制

目前登入權限是在前端原型內處理，適合用於流程確認與畫面設計，不等於正式資安。正式 ERP 需要改成後端登入、密碼雜湊、伺服器端權限檢查、操作紀錄與資料庫權限控管。
